Self-Signed Certificate

Since the server uses a self-signed certificate, you need to accept it in Brave first:

  1. Open your server URL directly in a new tab (e.g., https://192.168.1.50:8443/api/v1/auth/status)
  2. Click "Advanced" then "Proceed to ... (unsafe)"
  3. You should see a JSON response — the extension can now connect
