Self-Signed Certificate

Since the server uses a self-signed certificate, you need to accept it in Brave first:

  1. Open your server URL directly in a new tab (e.g., https://192.168.1.50:8443/api/v1/auth/status)
  2. Click "Advanced" then "Proceed to ... (unsafe)"
  3. You should see a JSON response — the extension can now connect

How to Export Passwords

Chrome / Brave
  1. Open chrome://password-manager/settings (or brave://password-manager/settings)
  2. Click "Download file" under "Export passwords"
  3. Confirm with your system password
  4. Select the downloaded CSV file above
Firefox
  1. Open about:logins
  2. Click the three dots menu (...) in the top right
  3. Select "Export Logins..."
  4. Confirm and save the CSV file
  5. Select the saved CSV file above
